# QuickPeek

A lightweight Linux space-to-preview file viewer, re-implementing the UX of the Windows app QuickLook.

QuickPeek provides instant previewing of selected files (starting with PNG, JPG, GIF, WebP, and SVG images in v1) in file managers such as Nautilus and Dolphin under modern Wayland compositors including Hyprland and Niri.
